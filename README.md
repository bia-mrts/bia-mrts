## Projetos em destaque

### Katu

Sistema desktop desenvolvido em WPF com .NET 8, focado em gestão de estoque e ponto de vendas.

Funcionalidades principais:

- Tela de gestão de estoque
- Tela de ponto de vendas
- Controle visual de status de estoque
- Interface desktop para uso em balcão

### PataTech

Sistema/API desenvolvido para gerenciamento de informações relacionadas a uma aplicação voltada ao atendimento e controle de dados de petshops e clínicas veterinárias.

Funcionalidades principais:

- Cadastro e gerenciamento de atendentes
- Agendamento e gerenciamento de serviços, animais, profissionais e tutores.
- Integração com banco de dados PostgreSQL
- Criação e aplicação de migrations
- Estruturação de backend com API
- Organização de entidades, controllers e rotas
- Publicação e sincronização da versão atualizada do sistema

Tecnologias utilizadas:

- C#
- .NET
- ASP.NET Core
- Entity Framework Core
- PostgreSQL
- Git e GitHub

### Livraria Hogsmeade

Sistema web CRUD desenvolvido em Java com Jakarta EE, JSP, Servlets, PostgreSQL, Maven e Apache Tomcat.

Funcionalidades principais:

- Cadastro de livros
- Listagem de registros
- Edição de informações
- Exclusão de livros
- Integração com banco de dados
